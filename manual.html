Updating MOUs日常更新

Open the office list and edit the All MOUs tab. Google Sheets saves automatically.打開辦公室總表，直接修改 All MOUs 分頁，Google Sheets 會自動儲存。

Add a new MOU新增 MOUAdd a row below the last row, fill it in, and set column R to Active.在最後一列下方新增一列，填好各欄，R 欄設為 Active。
Correct details修正資料Edit the cell directly: name, dates, country, MOU type.直接修改儲存格：學校名稱、日期、國家、MOU 類型等。
An MOU expires or endsMOU 到期或終止Change column R to Inactive. The row stays but leaves the dashboard count.把 R 欄改為 Inactive。該列保留在表中，但不再計入 Dashboard。
Remove a wrong entry刪除錯誤資料Delete the row. For real MOUs, prefer Inactive to keep the record.直接刪除該列。真實的 MOU 建議改為 Inactive 以保留紀錄。

Rules that keep the link working保持連動的規則

The dashboard finds data by tab name and column position. It reads columns A to R. Select a column to see its role.Dashboard 依分頁名稱和欄位位置讀取資料，讀取範圍是 A 到 R 欄。點選欄位查看說明。

Shown on the dashboard顯示在 Dashboard Read, not shown讀取但不顯示 Status (Active / Inactive)狀態欄（Active / Inactive） Free for new columns可新增欄位

Please keep請保留

  • The tab name exactly All MOUs分頁名稱必須是 All MOUs
  • The header in row 1, data from row 2第 1 列為標題列，資料從第 2 列開始
  • The order of columns A to RA 到 R 欄的順序
  • One MOU per row, no merged cells每列一筆 MOU，不合併儲存格
  • Joey’s view access to the office listJoey 對辦公室總表的檢視權限

Please avoid請避免

  • Renaming the All MOUs tab — the dashboard shows a sync error把 All MOUs 分頁改名，Dashboard 會顯示同步中斷
  • Inserting, deleting or moving columns within A to R在 A 到 R 欄之間插入、刪除或移動欄位
  • Replacing the file with a new copy, or moving it to the trash複製新檔案來取代它，或移到垃圾桶
  • Editing the retired Joey sheet修改已停用的 Joey 表

Colors, fonts, sorting and filters are all fine. Renaming the file is fine too, since the dashboard follows the file’s ID. The “↗ Sheet” link on the dashboard opens this office list.顏色、字型、排序、篩選都可以自由使用。檔案改名也沒關係，Dashboard 綁定的是檔案 ID。Dashboard 上的「↗ Sheet」連結會打開這份辦公室總表。

Backup and restore備份與還原

If data is changed or deleted by mistake, there are two ways to get it back.萬一資料被改錯或刪掉，有兩種方式可以找回來。

1

Version history第一層：版本記錄

Built into Google Sheets. Records every change: who, when, and what.Google Sheets 內建功能，自動記住每一次修改：誰、什麼時候、改了什麼。

Used by editors of the office list (the English team). For small mistakes.辦公室總表的編輯者（英文組）可以使用。適合處理小錯誤。

2

Daily backup files第二層：每日備份檔案

Separate full copies of All MOUs, saved every night in the “MOU Backups” folder of Joey’s Drive.每天晚上把 All MOUs 完整另存一份，放在 Joey Drive 的「MOU Backups」資料夾。

Joey shares the file you need. For major incidents.由 Joey 分享需要的檔案。適合處理大事故。

What happened?發生了什麼事？

Choose what happened to see which layer to use and how.選擇發生的情況，查看該用哪一層以及怎麼做。

Why two layers: version history lives inside the office list, so if the file is deleted it goes with it. The backup files are stored separately. Only the newest 30 are kept; days without changes are skipped, so 30 usually covers more than a month.為什麼需要兩層：版本記錄存在辦公室總表裡，檔案被刪除時會一起消失；備份檔案則是獨立存放的。備份只保留最新 30 份，沒有變動的日子不產生副本，所以通常可以涵蓋一個月以上。

Troubleshooting疑難排解

One-minute test一分鐘測試
  1. Open the dashboard and note the Active MOU count.打開 Dashboard，記下 Active MOU 筆數。
  2. In All MOUs, change column R of any Active row to Inactive.在 All MOUs 中，把任一 Active 列的 R 欄改為 Inactive。
  3. Wait about 20 seconds. The count drops by 1.等待約 20 秒，筆數會減少 1。
  4. Change it back to Active. The count returns.改回 Active，筆數恢復。

Still stuck? Send Joey a screenshot of the dashboard’s status line and the error message.仍無法解決時，請把 Dashboard 狀態列和錯誤訊息的截圖傳給 Joey。

Common tasks常見維護操作

Changing the EN MOU Live code修改 EN MOU Live 程式碼

Save → run testRead → Deploy → Manage deployments → Edit → Version: New version → Deploy. Editing keeps the same /exec URL, so index.html stays unchanged. A “New deployment” changes the URL, and LIVE_API_URL must then be updated.存檔 → 執行 testRead → 部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署。用「編輯」部署會保留同一個 /exec 網址，index.html 不用改；若用「新增部署作業」，網址會變，必須更新 LIVE_API_URL。

Changing the data source更換資料來源

Update the ID in three places: SHEET_ID in Code.gs, SOURCE_ID in BackupAllMOUs.gs, and SHEET_ID in index.html.同時修改三處 ID：Code.gs 的 SHEET_ID、BackupAllMOUs.gs 的 SOURCE_ID，以及 index.html 的 SHEET_ID。

The team needs to change columns A to R英文組要調整 A 到 R 欄

First update NUM_COLS and STATUS_COL in Code.gs and the matching column reads in index.html, then let the team change the sheet.先更新 Code.gs 的 NUM_COLS、STATUS_COL 以及 index.html 中對應的欄位讀取，再讓英文組改表。

Checking errors查看錯誤

Both Apps Script projects list every run and its errors under Executions in the left sidebar.兩個 Apps Script 專案左側的「執行項目」都有每次執行的紀錄和錯誤訊息。

Stopping the daily backup停止每日備份

In the MOU Backup project, open Triggers (clock icon) and delete backupAllMOUs.在 MOU Backup 專案的「觸發條件」（時鐘圖示）刪除 backupAllMOUs。
